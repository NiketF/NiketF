### PrivacyLens

**The first DPDPA 2023-aligned clause-level privacy policy analyzer trained on Indian company data.**

Identifies high-risk, vague, and non-compliant clauses. Benchmarked against Polisis, the academic standard for automated privacy policy analysis.

```
Stack    Python · RoBERTa · Gemini API
         Streamlit · HuggingFace · Scikit-learn

Dataset  816 manually annotated clauses
         from 9 Indian companies

Results  0.593 Macro F1
         0.660 Red-class F1 (high-risk)

Target   arXiv submission + FIRE 2025
```

**Why it is hard:** Custom two-phase training on a highly imbalanced legal corpus. Secondary vagueness classifier. Gemini API integration for plain-English clause simplification. The only publicly benchmarked DPDPA classifier on Indian company data.

[![Repo](https://img.shields.io/badge/View_Repo-181717?style=for-the-badge&logo=github&logoColor=white)](https://github.com/NiketF)

### AutoTest AI

**Zero-script E2E test generation. Point at a URL, get back a full browser interaction test suite.**

LLM analyzes live DOM structure, generates semantically meaningful interaction flows, then executes them in real browsers.

```
Stack    Python · FastAPI · Playwright
         React · LLM APIs

Scale    4+ real-world websites validated
         6+ automated test cases per site

Key      Self-healing selector system
         Test memory across runs

Impact   UI regression setup
         from hours down to minutes
```

**Why it is hard:** DOM context is serialized and fed to an LLM reasoning module that produces meaningful flows, not generic click scripts. Self-healing selectors recover from DOM mutations between runs.
