## ◈ Featured Projects

<details>
<summary><b>🔷 PrivacyLens — DPDPA-Aligned Privacy Policy Analyzer</b></summary>

<br/>

> The first AI system for clause-level privacy policy analysis aligned to India's Digital Personal Data Protection Act 2023. Identifies high-risk, vague, and non-compliant clauses in real-world privacy policies, benchmarked against Polisis.

<div align="center">

| Attribute | Detail |
|-----------|--------|
| **Stack** | Python · RoBERTa · Gemini API · Streamlit · Scikit-learn · HuggingFace |
| **Dataset** | 816 manually annotated clauses from 9 Indian companies |
| **Performance** | 0.593 Macro F1 · 0.660 Red F1 (high-risk clause detection) |
| **Regulatory Alignment** | India DPDPA 2023 — clause-level user rights mapping |
| **Impact** | Validated on real-world policy; 50/100 risk score generated end-to-end |
| **Repository** | [![GitHub](https://img.shields.io/badge/View%20Repo-181717?style=flat-square&logo=github&logoColor=white)](https://github.com/NiketF) |

</div>

Built a two-phase training pipeline on a custom-annotated dataset to address class imbalance and overfitting on a small legal corpus. Implemented vagueness detection as a secondary classifier and integrated Gemini API for plain-English clause simplification. Benchmarked outputs against Polisis — the academic standard for automated privacy policy analysis — to validate domain fidelity. Represents original research targeting arXiv and FIRE 2025.

<br/>

</details>

<details>
<summary><b>🔷 AutoTest AI — AI-Driven End-to-End Testing System</b></summary>

<br/>

> An autonomous E2E testing system that ingests a URL, analyzes live DOM structure via LLM reasoning, then generates and executes real browser interaction test flows — no manual test script authoring required.

<div align="center">

| Attribute | Detail |
|-----------|--------|
| **Stack** | Python · FastAPI · Playwright · React · LLM APIs |
| **Scale** | Validated across 4+ real-world websites |
| **Performance** | 6+ automated test cases generated and executed per website |
| **Architecture** | Modular pipeline with self-healing selector system and test memory |
| **Impact** | Reduces UI regression testing setup time from hours to minutes |
| **Repository** | [![GitHub](https://img.shields.io/badge/View%20Repo-181717?style=flat-square&logo=github&logoColor=white)](https://github.com/NiketF) |

</div>

Engineered a DOM parsing layer that feeds structured page context to an LLM reasoning module, which produces semantically meaningful interaction flows. The self-healing selector system recovers gracefully from DOM mutations between test runs. FastAPI backend serves test orchestration; React frontend exposes results with per-step validation output. An MVP that demonstrates agentic reasoning applied to a high-value developer workflow.

<br/>

</details>
